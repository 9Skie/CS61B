# 49. Group Anagrams

[LeetCode problem](https://leetcode.com/problems/group-anagrams/description/)

## Problem

Partition `strs` into groups so that each group contains strings that can be rearranged into one another. The groups may be returned in any order.

## Examples

### Example 1

```text
Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

### Example 2

```text
Input: strs = [""]
Output: [[""]]
```

### Example 3

```text
Input: strs = ["a"]
Output: [["a"]]
```

## Constraints

`1 ≤ len(strs) ≤ 10^4`. Each string has 0 to 100 lowercase English letters.
