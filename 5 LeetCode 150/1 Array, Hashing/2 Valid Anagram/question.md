# 242. Valid Anagram

[LeetCode problem](https://leetcode.com/problems/valid-anagram/description/)

## Problem

Check whether rearranging the letters of `s` can produce `t`. Return a boolean.

## Examples

### Example 1

```text
Input: s = "anagram", t = "nagaram"
Output: true
```

### Example 2

```text
Input: s = "rat", t = "car"
Output: false
```

## Constraints

Each string has 1 to `5 × 10^4` lowercase English letters.
