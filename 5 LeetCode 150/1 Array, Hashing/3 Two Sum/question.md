# 1. Two Sum

[LeetCode problem](https://leetcode.com/problems/two-sum/description/)

## Problem

Return the indices of two distinct elements in `nums` that sum to `target`. Exactly one valid pair exists, and either order of indices is accepted.

## Examples

### Example 1

```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```

### Example 2

```text
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

### Example 3

```text
Input: nums = [3,3], target = 6
Output: [0,1]
```

## Constraints

`2 ≤ len(nums) ≤ 10^4`, `-10^9 ≤ nums[i], target ≤ 10^9`
