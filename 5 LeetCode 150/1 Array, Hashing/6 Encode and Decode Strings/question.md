# 271. Encode and Decode Strings

[LeetCode problem](https://leetcode.com/problems/encode-and-decode-strings/description/) (Premium)

## Problem

Implement `encode(strs)` to turn a list of strings into one string and `decode(encoded)` to recover the exact list, preserving order and empty strings. The decoder receives only the encoded string.

## Examples

Examples from the public NeetCode version.

### Example 1

```text
Input: strs = ["Hello","World"]
Output: ["Hello","World"]
```

### Example 2

```text
Input: strs = [""]
Output: [""]
```

## Constraints

NeetCode allows 0 to 99 strings, each with 0 to 199 characters drawn from a 256-character alphabet.
