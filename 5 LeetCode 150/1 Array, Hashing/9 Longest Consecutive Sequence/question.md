# 128. Longest Consecutive Sequence

[LeetCode problem](https://leetcode.com/problems/longest-consecutive-sequence/description/)

## Problem

Find the maximum number of consecutive integer values present in `nums`, regardless of their positions. Repeated values contribute only once. The algorithm must run in linear time.

## Examples

### Example 1

```text
Input: nums = [100,4,200,1,3,2]
Output: 4
```

### Example 2

```text
Input: nums = [0,3,7,2,5,8,4,6,0,1]
Output: 9
```

### Example 3

```text
Input: nums = [1,0,1,2]
Output: 3
```

## Constraints

`0 ≤ len(nums) ≤ 10^5`, `-10^9 ≤ nums[i] ≤ 10^9`
