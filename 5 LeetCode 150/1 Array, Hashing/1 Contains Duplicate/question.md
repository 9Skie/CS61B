# 217. Contains Duplicate

[LeetCode problem](https://leetcode.com/problems/contains-duplicate/description/)

## Problem

Return `true` when two different indices in `nums` hold the same integer. Otherwise, return `false`.

## Examples

### Example 1

```text
Input: nums = [1,2,3,1]
Output: true
```

### Example 2

```text
Input: nums = [1,2,3,4]
Output: false
```

### Example 3

```text
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

## Constraints

`1 ≤ len(nums) ≤ 10^5`, `-10^9 ≤ nums[i] ≤ 10^9`
