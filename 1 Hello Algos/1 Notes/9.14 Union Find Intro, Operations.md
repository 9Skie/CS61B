Union find is a data structure that keeps track of elements which are split into one or more disjoint sets, it has only 2 primary operations: find and union.

- Two sets are disjoint if they have no elements in common. For example, `{A, B}` and `{C, D}` are disjoint because they don’t share any vertices.


But how exactly does one work? Let's look at an example. Union-find starts with a collection of elements, each in its own group. 

For example, `1`, `2`, `3`, and `4` start as `{1}`, `{2}`, `{3}`, and `{4}`.

- **`union(x, y)` merges the groups containing `x` and `y`.**
	- If you call `union(1, 2)`, you get `{1, 2}`, `{3}`, and `{4}`. Then if you call `union(2, 3)`, you get `{1, 2, 3}` and `{4}`. 

- **`find(x)` returns a label for the group containing `x`.** 
	- At this point, `find(1)` and `find(3)` return the same label, so you know they’re in the same group. `find(4)` returns a different label.

## Detail Look at Union Find Operations

First, we map each element to an integer.
- For `n` elements, assign IDs from `0` to `n − 1`. 

![[Screenshot 2026-11-11 at 2.47.41 PM.jpg|200]]

Then, we initialize each element as it's own group, each ID is represented through the index of the list, and stored inside that list, is the group which the element currently is in.
- We initialize each element as it's own group at first, so group = index
-

Now that you somewhat understand the union operation, as it just combines the elements within 2 groups into 1 group, what is find?

We  look at a element, and ask what group does it belong to, this is usually done by finding the root node of the group and returning that root node's value.
