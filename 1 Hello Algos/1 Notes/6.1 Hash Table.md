## Simple Implementation

Let's implement a hash table with an array

In a hash table, each empty slot in the array is called a bucket, and each bucket can store one key-value pair. A lookup therefore consists of finding the bucket for `key` and reading the `value` stored there.

To find the corresponding bucket for a given key, we use a hash function. A hash function maps a larger, variable length input space to a smaller, fixed length output space.
- It tells us where the corresponding key-value pair should be stored in the array.

![[Pasted image 20260921102226.png|300]]

There are many modern hash functions that we use in the modern era (for purposes we will see later), but for demonstration purposes, we will have an extremely simply hash function.

```markdown
index = hash(key) % capacity
```

![[Pasted image 20260921102517.png|500]]


The following code implements a simple hash table. Here, we encapsulate `key` and `value` into a class `Pair` to represent a key-value pair.

```python
class Pair:
    """Key-value pair"""

    def __init__(self, key: int, val: str):
        self.key = key
        self.val = val

class ArrayHashMap:
    """Hash table based on array implementation"""

    def __init__(self):
        """Constructor"""
        # Initialize array with 100 buckets
        self.buckets: list[Pair | None] = [None] * 100

    def hash_func(self, key: int) -> int:
        """Very Simple Hash function"""
        index = key % 100
        return index

    def get(self, key: int) -> str | None:
        """Query operation"""
        index: int = self.hash_func(key)
        pair: Pair = self.buckets[index]
        if pair is None:
            return None
        return pair.val

    def put(self, key: int, val: str):
        """Add and update operation"""
        pair = Pair(key, val)
        index: int = self.hash_func(key)
        self.buckets[index] = pair

    def remove(self, key: int):
        """Remove operation"""
        index: int = self.hash_func(key)
        # Set to None to represent removal
        self.buckets[index] = None

    def entry_set(self) -> list[Pair]:
        """Get all key-value pairs"""
        result: list[Pair] = []
        for pair in self.buckets:
            if pair is not None:
                result.append(pair)
        return result

    def key_set(self) -> list[int]:
        """Get all keys"""
        result = []
        for pair in self.buckets:
            if pair is not None:
                result.append(pair.key)
        return result

    def value_set(self) -> list[str]:
        """Get all values"""
        result = []
        for pair in self.buckets:
            if pair is not None:
                result.append(pair.val)
        return result

    def print(self):
        """Print hash table"""
        for pair in self.buckets:
            if pair is not None:
                print(pair.key, "->", pair.val)
```

## Hash Collision and Resizing

While in theory for a hash function, different inputs must sometimes map to the same output, but that's often not the case.

For the hash function in the above example, when the input `key`s have the same last two digits, the hash function produces the same output.

```markdown
12836 % 100 = 36
20336 % 100 = 36
```

This is called a hash collision, in our simple implementation example, two student IDs now point to the same name, which is clearly incorrect.

![[Pasted image 20260921103044.png|500]]



We won't talk about all the ways of how to solve this problem, but one idea is expanding the capacity of the hash table.

![[Pasted image 20260921103440.png|500]]

Like resizing an array, resizing a hash table requires migrating all key-value pairs from the original table to the new table, which is expensive. In addition, because the hash table capacity `capacity` changes, we must recompute the storage location of every key-value pair using the hash function, which further increases the cost of resizing. For this reason, programming languages typically reserve a sufficiently large hash table capacity to avoid frequent resizing.
