The knapsack problem is an excellent introductory problem for dynamic programming and is one of the most common problem forms in dynamic programming. It has many variants, such as the 0-1 knapsack problem, the unbounded knapsack problem, and the multiple knapsack problem.

We will look at the first one, the 0-1 knapsack problem.
- Given $n$ items and a knapsack with capacity $cap$, where the weight and value of the $i$-th item are $wgt[i-1]$ and $val[i-1]$, respectively. Each item can be selected at most once. What is the maximum value that can fit in the knapsack under the capacity limit?

![[Pasted image 20260923212402.png|500]]

If the above description is confusing, just by this example it simple means choose items with the highest total value while keeping their total weight at or below 50.

We can view the 0-1 knapsack problem as a process consisting of $n$ rounds of decisions, where for each item there are two decisions: not putting it in and putting it in, thus the problem satisfies the decision tree model.


Step 1: Define the subproblem and the DP table

For each item, we choose whether to take it or skip it. To describe a subproblem, we need two pieces of information, written as state $i,c$:

- **$i$:** The current item number we are deciding whether to take or skip.
- **$c$:** The remaining weight capacity in the knapsack.

The answer, $dp[i,c]$, is the highest total value obtainable using those items within that weight limit.

We store these answers in a table: rows represent item counts $0$ through $n$, and columns represent capacities $0$ through $cap$. Its size is $(n+1)\times(cap+1)$, and our final answer is $dp[n,cap]$.


Step 2: Express the answer using smaller subproblems

Consider item $i$. Let its weight be $w=wgt[i-1]$ and its value be $v=val[i-1]$. The arrays use $i-1$ because their indexing starts at $0$.

There are two choices:

- Skip item $i$: We gain no value from it and keep capacity $c$. Find the best value using the first $i-1$ items: $dp[i-1,c]$.
- Take item $i$: We gain value $v$ and have capacity $c-w$ left. Add the best value obtainable from the first $i-1$ items: $v+dp[i-1,c-w]$.

Both choices remove item $i$ from further consideration, choose whichever gives the larger total:

$dp[i,c]=\max(dp[i-1,c], v+dp[i-1,c-w])$

If $w>c$, the item does not fit, so we must skip it: $dp[i,c]=dp[i-1,c]$.

This is optimal substructure: the best answer for the current problem is built from the best answers to its smaller subproblems.


Step 3: Set the starting values and calculation order

If there are no items ($i=0$) or no remaining capacity ($c=0$), the maximum value is $0$. Set the first row and first column of the DP table to $0$.

Each entry $dp[i,c]$ uses answers from the previous row, where item $i-1$ was considered.

## Memoization

At state $i,c$, we are deciding about item $i$, with remaining weight capacity $c$. The function returns the maximum additional value we can obtain from item $i$ and the earlier items.

1. Check `mem[i][c]`. If it contains an answer, return that answer immediately. `-1` means this state has not been recorded yet.
2. Otherwise, explore the choices: skip item $i$, or take it if it fits.
3. Compare the total values from those two choices.
4. Store the larger value in `mem[i][c]`, then return it.

![[Pasted image 20260923215230.png|500]]

```python
def knapsack_dfs_mem(
    wgt: list[int], val: list[int], mem: list[list[int]], i: int, c: int
) -> int:
    """0-1 knapsack: Memoization search"""
    # If all items have been selected or knapsack has no remaining capacity, return value 0
    if i == 0 or c == 0:
        return 0
    # If there's a record, return it directly
    if mem[i][c] != -1:
        return mem[i][c]
    # If exceeds knapsack capacity, can only choose not to put it in
    if wgt[i - 1] > c:
        return knapsack_dfs_mem(wgt, val, mem, i - 1, c)
    # Calculate the maximum value of not putting in and putting in item i
    no = knapsack_dfs_mem(wgt, val, mem, i - 1, c)
    yes = knapsack_dfs_mem(wgt, val, mem, i - 1, c - wgt[i - 1]) + val[i - 1]
    # Record and return the larger value of the two options
    mem[i][c] = max(no, yes)
    return mem[i][c]
```

## Tabulation

Tabulation solves the same subproblems as memoization, but uses loops to fill the table from the smallest cases upward.

Here, $i$ is the current item number, and $c$ is the weight capacity available in the subproblem. `dp[i][c]` stores the best value obtainable after deciding about items $1$ through $i$.

1. Initialize the table with zeros. With no items or zero capacity, the best value is $0$.
2. Start with item $1$. Calculate its row for every capacity from $1$ to $cap$.
3. Move to the next item. For each capacity, compare skipping the item with taking it. Both options use answers from the completed previous row.
4. Continue through item $n$. The final answer is `dp[n][cap]`.

```python
def knapsack_tabulation(
    wgt: list[int], val: list[int], cap: int
) -> int:
    """Solve 0-1 knapsack using bottom-up tabulation."""
    n = len(wgt)

    # Row 0: no items. Column 0: no capacity.
    dp = [[0] * (cap + 1) for _ in range(n + 1)]

    # Fill one row for each item.
    for i in range(1, n + 1):
        weight = wgt[i - 1]
        value = val[i - 1]

        # Calculate the answer for each available capacity.
        for c in range(1, cap + 1):
            skip = dp[i - 1][c]

            if weight > c:
                # The item does not fit.
                dp[i][c] = skip
            else:
                # Take it, then use the remaining capacity
                # with items already considered.
                take = value + dp[i - 1][c - weight]
                dp[i][c] = max(skip, take)

    return dp[n][cap]
```
