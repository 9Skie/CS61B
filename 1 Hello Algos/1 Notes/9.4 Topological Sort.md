There's many real world situations that can be modeled as a graph with directed edges, where say, events must occur before others.

Take a CS degree for example, before taking data structures and algorithms you are likely asked to take a basic programming class.

In this diagram example, say we are at a uni and we wanted to take class H, we must take class D, E, but to take class D, we need to take class A, B.
- In this sense, there is ordering within the nodes of the graph.

![[Screenshot 2026-11-09 at 12.14.47 PM.jpg|500]]


This is all called topological ordering, it's an ordering (in an array like structure) of the nodes in a directed graph where every node points forward in the list.

If the only edges are $A \to C$ and $B \to C$, then both `A, B, C` and `B, A, C` are valid orderings. Both $A$ and $B$ must come before $C$, but either can come first.

Topological sort  is the process of finding a valid topological ordering. If the graph has a directed cycle, no valid ordering exists.


Why? There would be cyclic dependency issues since there is no way to start, as every graph is dependent on one another.

![[Screenshot 2026-11-09 at 12.22.36 PM.jpg|500]]

To detect if a graph contains a directed cycle, and therefore cannot contain a topological ordering, a possibility is to use Tarjan/Kosaraju's algorithm to detect strongly connected components (cycles, in simple understanding here).



So how does this sort work?

1. Pick an unvisited node.
2. Beginning with the selected node, do a depth-first search (DFS), exploring only unvisited nodes.
3. Just before the DFS call for the current node returns, add that node to the topological ordering. Fill the ordering from right to left.
4. Repeat until all nodes have been visited.

While checking outgoing edges during DFS, if an edge leads back to a node on the current DFS path, you’ve found a directed cycle. Stop, since no topological ordering exists.

If this sounds confusing in theory, lets look at an actual example.

![[Screenshot 2026-11-09 at 12.34.55 PM.jpg|500]]


We first pick a random node, say node H, and we begin DFS on the node, this will put DFS recursion call from H, to J, to M on the stack call stack.

![[Screenshot 2026-11-09 at 12.37.01 PM.jpg|500]]

Now that we reached M, M performs DFS and realizes there's no other vertices to visit, so it returns, adding itself to the last node in the topological ordering.

![[Screenshot 2026-11-09 at 12.39.43 PM.jpg|500]]


Then node J performs DFS, it still can visit node L, so it does so, node L performs DFS and finds itself having nowhere to go, so it returns and adds itself before M.

![[Pasted image 20261109124136.png|500]]


Then we backtrack and add J, then H continues DFS, which goes to node I, and then there's no nodes to visit from I, and it returns as well.

![[Screenshot 2026-11-09 at 12.43.41 PM.jpg|500]]


Then H finally returns and puts itself before all the previous nodes we've inputted.

![[Screenshot 2026-11-09 at 12.47.23 PM.jpg|500]]


Now that we completed our first DFS, we can pick another randomly unvisited node and continue our DFS from there on.

![[Screenshot 2026-11-09 at 12.51.22 PM.jpg|500]]

## Pseudocode 


```python
function topsort(graph):
    N = graph.numberOfNodes()
    visited = empty hash set
    active = empty hash set
    ordering = array of length N
    i = N - 1

    for at in graph.nodes():
        if at not in visited:
            visitedNodes = []
            dfs(at, visited, active, visitedNodes, graph)

            for node in visitedNodes:
                ordering[i] = node
                i = i - 1

    return ordering


function dfs(at, visited, active, visitedNodes, graph):
    visited.add(at)
    active.add(at)

    for neighbor in graph.neighbors(at):
        if neighbor in active:
            raise error("Directed cycle")

        if neighbor not in visited:
            dfs(neighbor, visited, active, visitedNodes, graph)

    active.remove(at)
    visitedNodes.append(at)
```

Notice how in the top sort function, we are inserting values from the end of the array and not in front of the array.
