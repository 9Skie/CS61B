The backtracking algorithm is a method for solving problems through exhaustive search. We start from an initial state and exhaustively search all possible solutions. When a correct solution is found, it is recorded. This process continues until a solution is found or all possible choices have been tried without finding a solution.

For example, DFS (depth first search) uses backtracking. 
- Starting at node `A`, we follow an unexplored neighbor, then another, going as deep as possible. When the current node has no unexplored neighbors, we return to the previous node and try another unexplored branch.

The essential pattern is:
1. **Make a choice.**
2. **Explore what follows from it.**
3. **Undo that choice so you can try another.**
