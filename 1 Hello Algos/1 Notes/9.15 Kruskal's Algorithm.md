Kruskal's algorithm, is another way to get a minimum spanning tree of a undirected graph.

What does this mean in practice? Consider this graph:

![[Screenshot 2026-11-11 at 3.23.47 PM.jpg|500]]


We pick the smallest edge on the graph, in this case `C-E` with a weight of 1.

![[Screenshot 2026-11-11 at 3.25.04 PM.jpg|500]]

Then, we pick the next smallest edge that's not in the MST, and also that doesn't create a cycle (this is for the definition of an MST), in this case it's `A-B` with a weight of 2.

![[Screenshot 2026-11-11 at 3.25.52 PM.jpg|500]]

We continue and pick a random node from the 3 same weighted nodes, in this case `A-D`.

![[Screenshot 2026-11-11 at 3.26.58 PM.jpg|500]]

Then we add `A-C`.

![[Screenshot 2026-11-11 at 3.27.50 PM.jpg|500]]


Now, look at the rest of the edges, we can't add `B-E` as that creates a cycle, we can't add `B-C` as that creates a cycle, and we can't add `D-C` as that also creates a cycle, so we use `D-F`.

![[Screenshot 2026-11-11 at 3.28.47 PM.jpg|500]]

And finally end with `F-G`.


Now... the question is, how does this relate to union sets?

At the start of Kruskal’s algorithm, each vertex is in its own set. As we choose edges, each set represents a group of vertices that are already connected by those edges.

We consider edges from lowest to highest weight. 
- For each edge, `find` gives us the representative ID of each endpoint’s set. 
- If the IDs differ, we add the edge to the MST and use `union` to merge the two sets.

In our example, `C–E` is the lightest edge, so we add it to the MST and merge `{C}` and `{E}` into `{C, E}`. 

Then `A–B` merges `{A}` and `{B}` into `{A, B}`.

Next, `A–D` adds `D` to that set, giving us `{A, B, D}`. 

Finally, `A–C` joins `{A, B, D}` and `{C, E}` into `{A, B, C, D, E}`.

When we consider `B–E`, both endpoints have the same representative ID. 
- That tells us `B` and `E` are already connected by the edges we’ve chosen. Adding `B–E` would create a cycle, so we skip it, and this check continues to make sure no cycles are created.

## Pseduocode

```python
# G = (V, E) is a connected, undirected graph.
# w gives the weight of each edge.

function kruskal(G, w):
    for each vertex u in V:
        makeset(u)

    X = empty set
    sort E by increasing weight w

    for each edge {u, v} in sorted E:
        if find(u) != find(v):
            add {u, v} to X
            union(u, v)

    return X

function makeset(x):
    parent[x] = x
    rank[x] = 0

function find(x):
    while x != parent[x]:
        x = parent[x]
    return x

function union(x, y):
    rootX = find(x)
    rootY = find(y)

    if rootX == rootY:
        return

    if rank[rootX] > rank[rootY]:
        parent[rootY] = rootX
    else:
        parent[rootX] = rootY
        if rank[rootX] == rank[rootY]:
            rank[rootY] += 1
```
