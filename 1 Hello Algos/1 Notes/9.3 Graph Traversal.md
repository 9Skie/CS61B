Something very important to graph theory is 'graph traversal algorithms', like, how do we even process every node in a graph given all these complicated relationships?

There's breadth first search and depth first search.

---

## Breadth First Search

Breadth first search, similar to how it is used in trees, starts from a node, and systematically visits all of it's neighbors. Then it proceeds by visiting the neighbors of the nodes that have been visited first, leading to a layer by layer exploration of the graph.

![[Pasted image 20260922164202.png|500]]


- The resulting graph generated by this is called a BFS tree.

![[Screenshot 2026-09-22 at 3.21.43 PM.jpg|400]]


BFS is typically implemented with the help of a queue, as shown in the code below. The queue has a "first in, first out" property, which aligns with the BFS idea of "near to far".

1. Add the starting vertex `startVet` to the queue and begin the loop.
2. In each iteration of the loop, pop the vertex at the front of the queue and record it as visited, then add all adjacent vertices of that vertex to the back of the queue.
3. Repeat step `2.` until all vertices have been visited.

![[Pasted image 20260922164715.png|500]]

![[Pasted image 20260922164723.png|500]]

```python
def graph_bfs(graph: GraphAdjList, start_vet: Vertex) -> list[Vertex]:
    """Breadth-first traversal"""
    # Use adjacency list to represent the graph, in order to obtain all adjacent vertices of a specified vertex
    # Vertex traversal sequence
    res = []
    # Hash set for recording vertices that have been visited
    visited = set[Vertex]([start_vet])
    # Queue used to implement BFS
    que = deque[Vertex]([start_vet])
    # Starting from vertex vet, loop until all vertices are visited
    while len(que) > 0:
        vet = que.popleft()  # Dequeue the front vertex
        res.append(vet)  # Record visited vertex
        # Traverse all adjacent vertices of this vertex
        for adj_vet in graph.adj_list[vet]:
            if adj_vet in visited:
                continue  # Skip vertices that have been visited
            que.append(adj_vet)  # Only enqueue unvisited vertices
            visited.add(adj_vet)  # Mark this vertex as visited
    # Return vertex traversal sequence
    return res
```

## Depth First Search

Depth first search starts from a node, then in every iteration selects (probably) a random neighbor node as the next node and continues this way until it hits a dead end. Then, it goes to the last node with unvisited node in it's neighborhoods and continues depth first search from there.

- As expected, we get a DFS tree!

This "go as far as possible then return" algorithm paradigm is typically implemented using recursion. Similar to breadth-first search, in depth-first search we also need a hash set `visited` to record visited vertices and avoid revisiting.

![[Pasted image 20260922164743.png|500]]

![[Pasted image 20260922164750.png|500]]

The reason we use a hash for 'visited' is such that when we are reaching a node in the DFS, we don't know if it has been visited or not, the way to check that in constant time is through a hash table.

```python
def dfs(graph: GraphAdjList, visited: set[Vertex], res: list[Vertex], vet: Vertex):
    """Depth-first traversal helper function"""
    res.append(vet)  # Record visited vertex
    visited.add(vet)  # Mark this vertex as visited
    # Traverse all adjacent vertices of this vertex
    for adjVet in graph.adj_list[vet]:
        if adjVet in visited:
            continue  # Skip vertices that have been visited
        # Recursively visit adjacent vertices
        dfs(graph, visited, res, adjVet)

def graph_dfs(graph: GraphAdjList, start_vet: Vertex) -> list[Vertex]:
    """Depth-first traversal"""
    # Use adjacency list to represent the graph, in order to obtain all adjacent vertices of a specified vertex
    # Vertex traversal sequence
    res = []
    # Hash set for recording vertices that have been visited
    visited = set[Vertex]()
    dfs(graph, visited, res, start_vet)
    return res
```
