There's many data structures: arrays, linked lists, stacks, queues, hash tables... they can be classified from two dimensions: "logical structure" and "physical structure".


## Logical Structure

The logical structure of data reveals the logical relationships between data elements, which are categorized in 'linear' and 'non-linear'.

Non-linear data structures can be further divided into tree structures and network structures.

## Physical Structure

Now, we understand the logical structure of data structures, what is the physical structure? This is how data is literally sitting on ram based on the logical structure of data.

When an algorithm program runs, the data being processed is mainly stored in memory, and the system accesses data at the target location through memory addresses.

![[Pasted image 20260918094855.png|500]]

Memory is a shared resource for all programs. When a block of memory is occupied by a program, it usually cannot be used by other programs at the same time. Therefore, in the design of data structures and algorithms, memory resources are an important consideration.

Memory usage of a data structure can be divided into contiguous space storage (how an array is stored in memory) and dispersed space storage (how a linked list is stored in memory).
- All data structures are implemented based on arrays, linked lists, or a combination of both.
