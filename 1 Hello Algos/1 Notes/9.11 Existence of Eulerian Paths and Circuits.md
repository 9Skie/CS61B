A Eulerian path is a path of edges that visits all the edges of a graph.

![[Screenshot 2026-11-10 at 9.17.18 PM.jpg|400]]

And from it, we can distinguish 2 different types of paths:
- open: where the eulerian path ends on a different node than where it started
- closed: where the eulerian path ends on the same node than where it started, this is also called a circuit

Similarly, an Eulerian circuit (or cycle) is an Eulerian path which starts and ends on the same vertex.

![[Screenshot 2026-11-10 at 3.19.31 PM.jpg|400]]

But, how do we determine whether an Eulerian path or circuit exists?


An Eulerian path uses every edge exactly once. An Eulerian circuit does the same and ends where it started.

| Graph type | Eulerian circuit                               | Eulerian path                                                                                                   |
| ---------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Undirected | Every vertex has even degree.                  | Exactly two vertices have odd degree. In the second case, those two vertices are the endpoints.                 |
| Directed   | Every vertex has equal indegree and outdegree. | The start has one extra outgoing edge, the end has one extra incoming edge, and every other vertex is balanced. |

It differs based on undirected and directed graphs.

![[Screenshot 2026-11-10 at 9.14.43 PM.jpg|500]]

- Undirected Graphs:
	- the degree of a node is how many edges are attached to it
- Directed Graphs:
	- we have incoming edges and outgoing edges, and so the we have what's called indegree and outdegree respectively.
