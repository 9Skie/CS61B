Given a dataset of size $n$, we can use linear search, binary search, tree search, hash-based search, and other methods to search for the target element.

![[Pasted image 20260922173520.png|500]]

| | Linear search | Binary search | Tree search | Hash-based search |
|---|---|---|---|---|
| Search element | $O(n)$ | $O(\log n)$ | $O(\log n)$ | $O(1)$ |
| Insert element | $O(1)$ | $O(n)$ | $O(\log n)$ | $O(1)$ |
| Delete element | $O(n)$ | $O(n)$ | $O(\log n)$ | $O(1)$ |
| Extra space | $O(1)$ | $O(1)$ | $O(n)$ | $O(n)$ |
| Data preprocessing | / | Sorting $O(n \log n)$ | Tree building $O(n \log n)$ | Hash table building $O(n)$ |
| Data ordered | Unordered | Ordered | Ordered | Unordered |

Linear search is extremely simple, so we won't even look at it, tree search is already implemented at the binary search tree, so we will simply look at binary search in deail.
