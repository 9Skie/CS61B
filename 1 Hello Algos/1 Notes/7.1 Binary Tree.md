A binary tree is a recursive data structure that models the hierarchical relationship between "ancestors" and "descendants", meaning that trees can contain subtrees that are similar to itself.

Similar to a linked list, the basic unit of a binary tree is a node, and each node contains a value, a reference to its left child node, and a reference to its right child node.
- Each node has two references (pointers), pointing respectively to the left-child node and right-child node. This node is called the parent node of these two child nodes.

There's more terminology involved!

- Root node: The node at the top level of a binary tree, which does not have a parent node.
- Leaf node: A node that does not have any child nodes, with both of its pointers pointing to `None`.
- Edge: A line segment that connects two nodes, representing a reference (pointer) between the nodes.
- The level of a node: It increases from top to bottom, with the root node being at level 1.
- The degree of a node: The number of child nodes that a node has.
- The height of a binary tree: The number of edges from the root node to the farthest leaf node.
- The depth of a node: The number of edges from the root node to the node.
- The height of a node: The number of edges from the farthest leaf node to the node.

To implement a basic binary tree, we just need to define tree nodes (we don't even need to define a tree data structure!)

```python
class TreeNode:
    """Binary tree node"""
    def __init__(self, val: int):
        self.val: int = val                # Node value
        self.left: TreeNode | None = None  # Reference to left child node
        self.right: TreeNode | None = None # Reference to right child node
```

Then we can initialize it with some values.

```python
# Initializing a binary tree
# Initializing nodes
n1 = TreeNode(val=1)
n2 = TreeNode(val=2)
n3 = TreeNode(val=3)
n4 = TreeNode(val=4)
n5 = TreeNode(val=5)

# Linking references (pointers) between nodes
n1.left = n2
n1.right = n3
n2.left = n4
n2.right = n5
```

---

There's many variations beyond the basic binary tree:

| Type                         | Description                                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Perfect binary tree**      | Every node has exactly two children except the leaves, and all leaves are at the same level.                        |
| **Complete binary tree**     | Every level is completely filled except possibly the last, which is filled from left to right.                      |
| **Full binary tree**         | Every node has either zero or two children, never exactly one.                                                      |
| **Balanced binary tree**     | The left and right subtrees stay close in height, their heights differ by at most one at every node.                |
| **Degenerate binary tree**   | Every non-leaf node has only one child, making the tree a single chain.                                             |
| **Binary search tree (BST)** | Values in each node’s left subtree are smaller, and values in its right subtree are larger, assuming no duplicates. |
