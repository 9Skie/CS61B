Merge sort is a sorting algorithm based on a divide-and-conquer strategy (which we'll get to very soon in a few chapters!)

1. **Divide phase**: Recursively split the array at the midpoint, reducing the problem of sorting a long array to the problem of sorting shorter arrays.
2. **Merge phase**: When a sub-array has length 1, stop dividing and start merging, continuously combining the shorter sorted sub-arrays on the left and right into a longer sorted array until the process is complete.

The division part seems extremely simple (and similar to binary search, almost, where we just keep finding midpoint), but how does the merge part work? That's something we need to see in detail.

![[Pasted image 20260922183922.png|500]]

Suppose we’re merging:
- Left:  [3, 7]
- Right: [2, 6]

We compare the first remaining element of each side, take the smaller one, and put it into a new array:

|Compare|Take|Result so far|
|---|---|---|
|3 and 2|2 from right|`[2]`|
|3 and 6|3 from left|`[2, 3]`|
|7 and 6|6 from right|`[2, 3, 6]`|

The right side is now empty, so we append the remaining **7** from the left. The merged result is **`[2, 3, 6, 7]`**.

In general, to merge two sorted sub-arrays:

1. Place a pointer at the beginning of each sub-array.
2. Compare the elements at the two pointers and copy the smaller one into a temporary array. If they are equal, take the left one to preserve stability.
3. Move forward only the pointer whose element was copied.
4. Repeat until one sub-array is exhausted, then append all remaining elements from the other.
5. Copy the merged result back into the corresponding section of the original array.

Merging a total of $n$ elements takes **$O(n)$ time**, since each element is copied into the result once.

```python
def merge(nums: list[int], left: int, mid: int, right: int):
    """Merge left subarray and right subarray"""
    # Left subarray interval is [left, mid], right subarray interval is [mid+1, right]
    # Create a temporary array tmp to store the merged results
    tmp = [0] * (right - left + 1)
    # Initialize the start indices of the left and right subarrays
    i, j, k = left, mid + 1, 0
    # While both subarrays still have elements, compare and copy the smaller element into the temporary array
    while i <= mid and j <= right:
        if nums[i] <= nums[j]:
            tmp[k] = nums[i]
            i += 1
        else:
            tmp[k] = nums[j]
            j += 1
        k += 1
    # Copy the remaining elements of the left and right subarrays into the temporary array
    while i <= mid:
        tmp[k] = nums[i]
        i += 1
        k += 1
    while j <= right:
        tmp[k] = nums[j]
        j += 1
        k += 1
    # Copy the elements from the temporary array tmp back to the original array nums at the corresponding interval
    for k in range(0, len(tmp)):
        nums[left + k] = tmp[k]

def merge_sort(nums: list[int], left: int, right: int):
    """Merge sort"""
    # Termination condition
    if left >= right:
        return  # Terminate recursion when subarray length is 1
    # Divide and conquer stage
    mid = (left + right) // 2  # Calculate midpoint
    merge_sort(nums, left, mid)  # Recursively process the left subarray
    merge_sort(nums, mid + 1, right)  # Recursively process the right subarray
    # Merge stage
    merge(nums, left, mid, right)
```
