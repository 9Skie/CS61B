2. Accessing Elements

Well... you fundamentally know how it works in C
- element's memory location = array memory start location + element length * element index

![[Pasted image 20260918101823.png|500]]

Accessing elements in an array is highly efficient; we can randomly access any element in the array in $O(1)$ time.

```python
def random_access(nums: list[int]) -> int:
    """Random access to element"""
    
    # Randomly select a number from the interval [0, len(nums)-1]
    random_index = random.randint(0, len(nums) - 1)
    
    # Retrieve and return the random element
    random_num = nums[random_index]
    
    return random_num
```



3. Inserting Elements

If we want to insert elements in the middle of an array, we have to shift all subsequent elements to the right, and then assign the value at that index.

![[Pasted image 20260918102507.png|500]]

You might go, wait, isn't the length of an array fixed? Then if we move everything to the right by 1, wouldn't this cause us to lose the last element out of the array?

Yeah, we'll find a solution later.

```python
def insert(nums: list[int], num: int, index: int):
    """Insert element num at index index in the array"""
    
    # Move all elements at and after index index backward by one position
    for i in range(len(nums) - 1, index, -1):
        nums[i] = nums[i - 1]
        
    # Assign num to the element at index index
    nums[index] = num
```

So, unless we have empty space sitting around inside an array, inserting is a costly operation...



4. Removing Elements

Similar to inserting elements, deleting an element causes all elements to shift (left) 1 index.

![[Pasted image 20260918102831.png|500]]

Note that after the deletion is complete, the original last element is no longer meaningful, this creates wasted memory.

```python
def remove(nums: list[int], index: int):
    """Remove the element at index index"""
    
    # Move all elements after index index forward by one position
    for i in range(index, len(nums) - 1):
        nums[i] = nums[i + 1]
```



5. Expanding Arrays

In complex system environments, programs cannot guarantee that the memory space after an array is available, making it unsafe to expand the array's capacity. Therefore, in most programming languages, the length of an array is immutable.

If we want to expand an array, we need to create a new, larger array and then copy the original array elements to the new array one by one. This is an $O(n)$ operation, which is very time-consuming when the array is large.

```python
def extend(nums: list[int], enlarge: int) -> list[int]:
    """Extend array length"""

    # Initialize an array with extended length
    res = [0] * (len(nums) + enlarge)
    
    # Copy all elements from the original array to the new array
    for i in range(len(nums)):
        res[i] = nums[i]
        
    # Return the extended new array
    return res
```
