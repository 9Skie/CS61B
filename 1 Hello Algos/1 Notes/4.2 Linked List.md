We know that arrays require contiguous memory, and when an array is very large, the system may not be able to provide such a large contiguous block. This is where the flexibility of linked lists becomes apparent.

A linked list is a linear data structure in which each element is a node object, and the nodes are connected through "references". A reference records the memory address of the next node, through which the next node can be accessed from the current node.

![[Pasted image 20260918125053.png|500]]

As we can see, the basic unit of a linked list is a node object.
- Each node contains two pieces of data: the node's "value" and a "reference" to the next node.
- - The first node of a linked list is called the "head node", and the last node is called the "tail node", the tail node points to "null".


1. Initializing a Linked List

Building a linked list involves two steps: first, initializing each node object; second, constructing the reference relationships between nodes.

```python
# Initialize linked list 1 -> 3 -> 2 -> 5 -> 4

# Initialize each node
n0 = ListNode(1)
n1 = ListNode(3)
n2 = ListNode(2)
n3 = ListNode(5)
n4 = ListNode(4)

# Build references between nodes
n0.next = n1
n1.next = n2
n2.next = n3
n3.next = n4
```

2. Inserting a Node

It'a a series of 3 steps! Suppose we want to insert a new node `P` between two adjacent nodes `n0` and `n1`, all we need is...

1. Create the new node `P`.
2. Make `P` point to `n1`.
3. Change `n0` so that it points to `P` instead of `n1`.

So the original relationship `n0 → n1` becomes `n0 → P → n1`.

![[Pasted image 20260918125818.png|500]]

```python
def insert(n0: ListNode, P: ListNode):
    """Insert node P after node n0 in the linked list"""
    
    n1 = n0.next
    P.next = n1
    n0.next = P
```

As we can see, this is literally just 2 steps, and such it is $O(1)$ complexity as composed to $O(n)$ complexity for an array.


3. Removing a Node

It's even simpler! This just takes 2 steps, suppose we want to remove a node `P` between  `n0` and `n1`, all we need is...

1. Make `n0` point to `n1` instead of `P`
2. (We don't have to worry about what `P` points to, since it doesn't matter)

![[Pasted image 20260918130219.png|500]]

```python
def remove(n0: ListNode):
    """Remove the first node after node n0 in the linked list"""
    
    if not n0.next:
        return
        
    # n0 -> P -> n1
    P = n0.next
    n1 = P.next
    n0.next = n1
```

This is also $O(1)$.


4. Accessing a Node

Accessing nodes in a linked list is less efficient than arrays, while accessing arrays is $O(1)$, accessing in a linked list is $O(n)$ because the program needs to start from the head node and traverse backward one by one until the target node is found.

```python
def access(head: ListNode, index: int) -> ListNode | None:
    """Access the node at index index in the linked list"""
    
    for _ in range(index):
        if not head:
            return None
        head = head.next
        
    return head
```

6. Variations of Linked Lists

There are 3 commons variations of linked lists:

- **Singly linked list**: The nodes of a singly linked list contain a value and a reference to the next node.
- **Circular linked list**: The tail node of a singly linked list point to the head node (connecting the tail to the head).
- **Doubly linked list**: A doubly linked list records references in both directions. The node definition of a doubly linked list includes references to both the successor node (next node) and the predecessor node (previous node).
