A traversal is defined as visiting each node in the binary tree once in some way, this could be done either in depth first or breadth first.
- Depth First: we vertically go down as far as possible, visiting all nodes along a branch before moving to the next.
- Breadth First: we go horizontally as far as possible, visiting all nodes at the same depth before moving to the next.

There are 3 common depth first traversals (pre-order, in-order, post-order) and 1 common breadth first traversals (level-order).

A question might be, why do we have so many traversals? They all serve their different purposes:
- **Pre-order:** Create a copy of the binary search tree.
- **In-order:** Output elements of binary search tree in order.
- **Post-order:** Backtrack and delete binary tree from memory.
- **Level-order:** Output elements in order that they were inserted.

## Level Order Traversal


Level-order traversal means visiting a tree one level at a time, from top to bottom and left to right. We visit the root first, then all nodes directly below it, then all nodes on the next level, and so on.

We use a queue to keep track of which nodes to visit next:

1. Put the root in the queue.
2. Remove the node at the front and visit it.
3. Add its children to the back of the queue, left child first, then right child, if they exist.
4. Repeat until the queue is empty.

![[Pasted image 20260921143518.png|500]]

```python
def level_order(root: TreeNode | None) -> list[int]:
    """Level-order traversal"""
    
    # Initialize queue, add root node
    queue: deque[TreeNode] = deque()
    queue.append(root)
    
    # Initialize a list to save the traversal sequence
    res = []
    
    while queue:
        node: TreeNode = queue.popleft()  # Dequeue
        res.append(node.val)  # Save node value
        if node.left is not None:
            queue.append(node.left)  # Left child node enqueue
        if node.right is not None:
            queue.append(node.right)  # Right child node enqueue
            
    return res
```

- **Time complexity is $O(n)$:** All nodes are visited once, using $O(n)$ time, where $n$ is the number of nodes.
- **Space complexity is $O(n)$:** In the worst case, like a full binary tree, before traversing to the bottom level, the queue contains at most $(n + 1)/2$ nodes simultaneously, occupying $O(n)$ space.

## Pre Order Traversal

We visit the root node first, then recursively visit the left subtree, then recursively visit the right subtree.
- For each node, it means visit them, traverse to it's left children, then traverse to it's right children.

![[Screenshot 2026-09-21 at 3.00.43 PM.jpg|200]]

Output: F, B, A, D, C, E, G, I, H

```python
def pre_order(root: TreeNode | None):
    """Preorder traversal"""
    if root is None:
        return
    # Visit priority: root node -> left subtree -> right subtree
    res.append(root.val)
    pre_order(root=root.left)
    pre_order(root=root.right)
```

## In Order Traversal

Starting from the root note, we recursively visit the left subtree, then recursively visit the right subtree.

For each node, it means traverse to it's left children, visit it, then traverse to it's right child.

![[Screenshot 2026-09-21 at 3.03.35 PM.jpg|200]]

Output: A, B, C, D, E, F, G, H, I

```python
def in_order(root: TreeNode | None):
    """Inorder traversal"""
    if root is None:
        return
    # Visit priority: left subtree -> root node -> right subtree
    in_order(root=root.left)
    res.append(root.val)
    in_order(root=root.right)
```

## Post Order Traversal

Starting from the root node, we recursively visit the left subtree, then recursively visit then recursively visit the right subtree.

For each node, it means traverse to it's left children, traverse to it's right children, then visit it.

![[Screenshot 2026-09-21 at 3.07.47 PM.jpg|200]]

Output: A, C, E, D B, H, I, G, F

```python
def post_order(root: TreeNode | None):
    """Postorder traversal"""
    if root is None:
        return
    # Visit priority: left subtree -> right subtree -> root node
    post_order(root=root.left)
    post_order(root=root.right)
    res.append(root.val)
```
