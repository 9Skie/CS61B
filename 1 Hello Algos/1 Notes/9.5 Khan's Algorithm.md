As we saw, the original DFS version fills the array from the last slot toward the first. Kahn’s algorithm appends nodes from the first slot toward the last.

The idea goes as such:

1. **Pick a node with no remaining dependencies.** An incoming edge means another node must come before it. If no incoming edges remain, you can put this node in the next open slot in the ordering.
2. **Remove that node and its outgoing edges.** You’ve already placed the node, so every node it points to has one fewer dependency left to wait for. When a node loses its last incoming edge, it becomes free to place.
3. **Repeat until all nodes are placed or you get stuck.** If nodes remain but none are free, each remaining node has an incoming edge from a remaining node. Following those edges backward eventually brings you back to a node you’ve already seen, so there’s a directed cycle.

## Psudocode

```python
# g is a directed graph represented as an adjacency list.
function FindTopologicalOrdering(g):
    n = g.size()
    in_degree = [0, 0, ..., 0]  # size n

    for (i = 0; i < n; i++):
        for (to in g[i]):
            in_degree[to] = in_degree[to] + 1

    # q holds unprocessed nodes with no remaining incoming edges.
    q = empty integer queue
    for (i = 0; i < n; i++):
        if in_degree[i] == 0:
            q.enqueue(i)

    index = 0
    order = [0, 0, ..., 0]  # size n

    while (!q.isEmpty()):
        at = q.dequeue()
        order[index++] = at

        for (to in g[at]):
            in_degree[to] = in_degree[to] - 1
            if in_degree[to] == 0:
                q.enqueue(to)

    if index != n:
        return null  # The graph contains a directed cycle.

    return order
```
