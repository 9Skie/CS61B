So, what is a minimum spanning tree?

Given an undirected graph with weighted edges, a MST is a subset of all the edges in the graph which connect all the vertices together without creating any cycles wile minimizing the total edge cost.

A graph can have multiple MSTs with different edges but the same minimum total weight. Prim’s and Kruskal’s can return different trees depending on how they break ties.


Prim's algorithm is on way to find such MSTs, and it works like this, here is an example of a graph.

![[Screenshot 2026-11-11 at 12.44.37 PM.jpg|500]]


We start with a random node, here, A for example.

![[Screenshot 2026-11-11 at 12.45.12 PM.jpg|500]]


Then, as Prim's is greedy, we look at all the unvisited nodes that A is connected to, and pick based on the smallest edge possible.

![[Screenshot 2026-11-11 at 12.46.16 PM.jpg|500]]

In this case, we can reach B, C, D from A, we pick to go to B since it has the lowest edge weight of 2.

![[Screenshot 2026-11-11 at 12.56.29 PM.jpg|500]]


Now again, we repeat this process, as we can reach D, C, and E from A and B.

![[Screenshot 2026-11-11 at 12.57.37 PM.jpg|500]]


Here, the edge from A to D, C, and from B to E is the same weight, so we just pick one of them at random, in this case we pick the edge from A to C.

![[Screenshot 2026-11-11 at 12.59.56 PM.jpg|500]]


Then we repeat this process of picking the smallest edge to an unvisited node.
- we have to make sure it's to an unvisited node not to make a cycle.

![[Screenshot 2026-11-11 at 1.01.37 PM.jpg|500]]


A natural question then to ask is, how do we keep track of these things?

- nodes that we've visited
- edges that we can use to visit other unvisited nodes
- edges that we've picked for our MST

We can keep track of these with three data structures.

- **Visited vertices.** A boolean array `visited` records which vertices are already in the tree. We mark `A` as visited when we start.
- **Candidate edges.** A min-priority queue stores edges by weight, so we can pull out the lightest one. Whenever we add a vertex to the tree, we put its edges to unvisited neighbors into the queue.
- **MST edges.** A list records the edges we actually choose.

## Pseudocode

```python
n = ... # Number of nodes in the graph.

pq = ... # PQ data structure; stores edge objects consisting of
         # {start node, end node, edge cost} tuples. The PQ sorts
         # edges based on min edge cost.

g = ... # Graph representing an adjacency list of weighted edges.
        # Each undirected edge is represented as two directed
        # edges in g. For especially dense graphs, prefer using
        # an adjacency matrix instead of an adjacency list to
        # improve performance.

visited = [false, ..., false] # visited[i] tracks whether node i
                              # has been visited; size n

# s - the index of the starting node (0 ≤ s < n)
function lazyPrims(s = 0):
    m = n - 1 # number of edges in MST
    edgeCount, mstCost = 0, 0
    mstEdges = [null, ..., null] # size m
    addEdges(s)

    while (!pq.isEmpty() and edgeCount != m):
        edge = pq.dequeue()
        nodeIndex = edge.to

        if visited[nodeIndex]:
            continue

        mstEdges[edgeCount++] = edge
        mstCost += edge.cost

        addEdges(nodeIndex)

    if edgeCount != m:
        return (null, null) # No MST exists!

    return (mstCost, mstEdges)

function addEdges(nodeIndex):
    # Mark the current node as visited.
    visited[nodeIndex] = true

    # Iterate over all edges going outwards from the current node.
    # Add edges to the PQ which point to unvisited nodes.
    edges = g[nodeIndex]
    for (edge : edges):
        if !visited[edge.to]:
            pq.enqueue(edge)
```
