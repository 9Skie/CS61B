A sorting algorithm arranges a set of data in a specific order, it's how we allow binary search to work in the first place.

When we evaluate how good a sorting algorithm is, we think about it in 3 dimensions:

- **Execution efficiency:** Sorting should use few operations and have low time complexity, especially for large datasets.
    
- **In-place property:** Sorting directly rearranges the original array with little extra memory.
    
- **Stability:** Equal elements retain their original relative order after sorting.

We will only understand some of the ideas:

- **Selection sort:** Repeatedly find the smallest remaining element and put it in its place.
- **Insertion sort:** Grow a sorted section by inserting each new element where it belongs.
- **Quick Sort**: Recursively divide and sort smaller arrays. 
- **Merge sort:** Split the array into halves, sort them, then merge them.
- **Heap sort:** Build a heap and repeatedly move the largest element to the end.
